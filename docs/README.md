# Mansi Kumari — Portfolio

A single-page personal portfolio built with only HTML and CSS.

## Sections
- **Header / Nav** — sticky flexbox navbar with anchor links
- **Hero** — introduction and portrait
- **About** — bio and quick facts
- **Tech Stack** — skills grouped as chips
- **Projects** — three project cards (flexbox row, hover lift)
- **Achievements & Certifications** — five cards
- **Contact** — email, LinkedIn and GitHub links

## What I practised
- Semantic tags: `header`, `nav`, `main`, `section`, `article`, `footer`
- The CSS box model (margin, border, padding)
- Flexbox for the navbar and card rows
- CSS variables for colours and fonts (`:root` in `style.css`)

## Run it
Open `index.html` in any browser. No build step needed.
