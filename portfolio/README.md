# Mansi Kumari | Portfolio

A single-page personal portfolio built with plain HTML and CSS: header with navigation, About, Projects and Contact sections.

## Run it

Open `index.html` in your browser. No build step or install needed.

## Structure

- `index.html`: page content using semantic tags (header, nav, main, section, footer)
- `style.css`: styles, with 4 colours and 1 font defined once as CSS variables in `:root`
- `images/`: profile photo (`profile.jpg`) and other images
